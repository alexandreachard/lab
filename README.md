# Lab

Personal engineering lab for testing, building, breaking, and learning across cloud infrastructure, automation, and platform engineering.

## What's Inside

### Patterns
Reusable infrastructure patterns refined from real-world experience:
- **Azure Enterprise Governance** — Management group hierarchy, policy assignments, and subscription-level controls
- **Private Endpoint Factory** — Modular Terraform pattern for deploying Azure Private Endpoints with DNS integration
- **Terraform Modules** — Reusable modules for Azure Container Apps, networking, Private DNS Zones, and Private Endpoints

### Experiments
Hands-on explorations of cloud services and architectures:
- **Azure RAG Network Isolation** — Securing Retrieval-Augmented Generation workloads with Private Endpoints and network isolation
- **GCP Classic VPN** — Site-to-site VPN connectivity on Google Cloud
- **GCP Compute Instance / Firewall Rules / MIG with LB** — GCP compute patterns from instances to managed groups behind load balancers
- **Netbox** — Network source of truth deployment and testing

### Snippets
Quick-reference code for daily engineering work:
- Bash, Dev Containers, Docker, Kubernetes playground configs

### Runbooks
Operational procedures documented as code:
- Netbox update procedures

### Tools
Custom utilities:
- Azure Blob Uploader

## Stack

Primary languages: HCL (Terraform), Bash, Docker

## Purpose

This lab is where I prototype, validate, and document infrastructure ideas before applying them at scale. It reflects how I learn — by building.
