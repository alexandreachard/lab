# Technical Sandbox & Engineering Lab

This is my personal playground for building, breaking, and testing things. It is a live workspace for my engineering experiments, not a polished portfolio of perfect templates.

I use this repo to write Python and Bash scripts, test network setups, mess around with cloud platforms, and log what happens when things inevitably break.

---

## Repository Structure

### experiments/

The raw work. This contains my drafts, implementations, scripts ideas, and post-mortems for everything from Python and Bash automation to Azure, GCP, Kubernetes, and NetBox configurations.

### patterns/

The good stuff. Once an experiment works well, I clean it up and turn it into a reusable, parameter-driven blueprint or automation tool here.

### learn/

This section tracks my foundational learning baselines, core command syntax, and practical runtime playgrounds for Bash, Docker, and localized Kubernetes testing.

---

## Navigating My Platform Journey

Start in `experiments/` to see the raw code, scripts, and failure logs. If you want to see how those ideas evolve into production-ready blueprints, check out `patterns/`.

For the full breakdown of why I made certain design decisions or the economic trade-offs involved, I write longer posts over on my blog.
